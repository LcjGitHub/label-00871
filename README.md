# Random Lottery System (随机抽签系统)

## 1 How to Run

### 本地直接运行 (开发模式)
由于项目使用 ES6 Modules，直接双击 `index.html` 可能会因为浏览器的 CORS 策略（file:// 协议）受限。建议使用以下方式：
1. 使用 VS Code 的 "Live Server" 插件打开 `index.html`。
2. 或者在项目根目录运行 Python 简易服务器：
   ```bash
   python3 -m http.server 8000
   ```
   然后访问 `http://localhost:8000`。

### Docker 运行 (生产模式)
本项目支持跨平台构建（x86/ARM）。

1. **构建并启动**
   ```bash
   docker-compose up -d --build
   ```

2. **访问系统**
   打开浏览器访问 `http://localhost:8080`

3. **动态修改数据**
   修改本地的 `data.js` 文件，刷新浏览器即可生效（无需重启容器）。

## 3 测试账号 / 数据

系统不需要登录账号。默认提供的测试数据位于 `data.js` 文件中，包含 15 位模拟候选人：

- **部门**: 研发部, 设计部, 产品部, 市场部, 人事部, 财务部, 运营部, 行政部
- **示例人员**: 张三 (ID: 101), 李四 (ID: 102) ... 冯十七 (ID: 115)

如需测试 "数据耗尽" 场景，可连续抽取多次直到剩余人数为 0。

## 4 题目内容

任务描述：在日常教学、活动组织、团队建设等场景中，常需要进行随机抽签以确保公平性与趣味性。请你设计并开发一个基于Web 前端技术的随机抽签系统，通过可视化界面和动态交互效果，实现数据驱动的抽签功能。具体需求：1.  内容要求：- 抽签数据来源于外部 data.js 文件，数据结构应包含候选项信息（如姓名、编号等）。- 首页包含网站标题（如"随机抽签系统"）、功能说明、操作区域和结果展示区域。- 数据加载成功后，应在页面中显示当前可抽选的总人数或项目数。2.  功能要求：- 使用 JavaScript 动态加载并解析 data.js 文件中的数据。- 提供用户可配置选项：- 画面滚动速度（如快速、中速、慢速，或自定义数值）- 随机抽选数量（如一次抽取 1 人、3 人、5 人等）- 实现抽签动画效果，在滚动过程中随机展示候选项，营造悬念感。- 点击"开始抽签"按钮后，根据用户设置的参数执行抽签，并在动画结束后显示最终结果。- 支持"重置"或"再次抽签"功能，清空上次结果并允许重新配置参数。- 确保抽签算法的随机性与公平性，避免重复抽取同一项（除非需求允许）。- 所有资源（包括 data.js 文件）应本地存放，确保离线可运行。3. 风格要求：- 采用现代简洁设计，主色调建议使用科技蓝、活力橙或专业灰，体现系统的严肃性与趣味性平衡。- 字体清晰易读，按钮样式醒目，交互反馈及时（如按钮点击状态、加载提示）。- 页面结构清晰，操作区域与结果展示区域分离明确，留白合理。- 抽签动画流畅自然，速度可控，避免视觉疲劳。- 支持响应式布局，在手机和电脑上均能正常操作与显示结果。

**功能概览**：
- **数据驱动**：外部 `data.js` 导入候选项。
- **可视化交互**：滚动动画、卡片展示、Toast 提示。
- **高度配置**：支持调节滚动速度（慢/中/快）和单次抽取数量（1/3/5/10人）。
- **公平性**：算法保证单次运行周期内不重复抽取，支持重置。
- **美观性**：科技蓝主色调，卡片式设计，响应式布局适配移动端。
- **工程化**：Docker 容器化交付，支持 ARM/x86 架构。

## 项目结构说明

```text
.
├── data.js                 # 外部数据源 (用户可配置)
├── index.html              # 入口文件
├── nginx.conf              # Nginx 配置文件
├── Dockerfile              # 多阶段构建文件
├── docker-compose.yml      # 容器编排
├── src/
│   ├── css/                # 样式文件 (拆分为 base, components, etc.)
│   └── js/                 # 逻辑文件 (ES Modules 模块化开发)
```

## 技术栈

- **Core**: HTML5, CSS3 (Flexbox/Grid/Variables), Vanilla JavaScript (ES6+)
- **Architecture**: MVC Pattern, ES Modules
- **Ops**: Docker, Nginx (Alpine Linux)
